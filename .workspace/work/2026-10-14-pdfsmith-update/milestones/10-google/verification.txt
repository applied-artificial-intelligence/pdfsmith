Optional processor_version is sent in the resource name. skip_human_review=true;

Google SDK 3.16.x and storage 3.17.x perform actual REST serialization, upload,
polling, typed protobuf metadata decode and JSON shard downloads through a strict
in-memory HTTP adapter. SDK/API/direct/async/console checks passed four isolated,
noneditable extra-only installs, Python 3.10-3.13. Ordinary DNS/TCP is denied.
The 9MB controlled PDF exercises actual resumable upload and server checksum
confirmation. Its upload hash matches the original PDF; smaller PDFs use actual
SDK multipart upload. No test/fixture dependencies mask target requirements.
Evidence: installed-3.*.json, run/install logs and raw-outputs.tar.gz. These contain
exact package/wheel/source/dependency/input/output identities and outgoing URLs.

Complete success requires the matching known terminal operation, SUCCEEDED
metadata, exactly one matching input-document status with code zero and an output
destination inside the owned prefix/bucket. Shards must have complete unique
indices/counts, contiguous text offsets and complete ordered page coverage.
Document-level errors, missing/mismatched responses and incomplete shards raise.
Blank sync output is valid only with complete pages. Partial semantic omissions
cannot be detected by metadata alone and are outside this contract.

No submission retries. Polling is explicitly bounded. Known jobs receive a bounded
cancellation request on uncertainty, followed by one bounded terminal-state check.
Unknown jobs retain their input/output resources and surface operation/GCS IDs.
Only confirmed terminal work or rejected submissions permit owned-prefix deletion;
object deletion uses generation preconditions. Storage, operations and processor
sessions close on all paths. Completed output plus cleanup error is retained in
BackendOperationError and separate private CLI recovery JSON.

SDK compatibility evidence: Document AI 3.16.0 overrides the REST cancel routing
without a body binding; real cancel_operation raised KeyError('body'). The wrapper
adds the missing body='*' to its owned operations transport before cancellation.
The core OperationsRestTransport.close() raises NotImplementedError, so its owned
session is closed directly. These localized SDK seams explain the narrow pin.
The tests actually emit the cancel POST and assert three owned session closes.
