AWS renders each PDF page at 150 DPI in a fresh native worker, bounds image
geometry/bytes, sends PNG Bytes to synchronous Textract, requires one PAGE block
and DocumentMetadata.Pages=1 per response, and closes its client on every exit.
No automatic SDK retry. Native handles are scoped to the worker's context.
Azure standard-tier limits are checked before upload; F0 page truncation is
rejected by exact returned page coverage. Polling uses NoPolling plus explicit
bounded GETs, avoiding an SDK thread that could outlive the wrapper deadline.
Known terminal operations have their owned analysis result deleted. Unknown
completion retains the operation ID without claiming remote cancellation.
Both adapters preserve primary errors and completed content on cleanup failure.
